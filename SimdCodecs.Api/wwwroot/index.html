纯托管 .NET 10 图片编解码服务 · 图片只在本地进程内处理，不落临时文件、不上传第三方
正在连接服务…

1 · 选择图片

拖放图片到这里，或点击选择 支持多选 · HEIC / TIFF / JPEG 2000 / JBIG2 / QOI / GIF / PNG / JPEG / WebP …

2 · 转换参数

编解码层只支持 1/2ⁿ 解码期降采样；任意尺寸缩放、滤镜、水印与裸像素导出见下方处理层（纯托管实现，不需要 SkiaSharp）。

3 · 图像处理与 CV 输入

裸像素返回连续字节，响应头带 X-Width / X-Height / X-Stride / X-Cv-Otsu-Threshold / X-Cv-Text-Rows，可直接喂给 OCR 或 OpenCV。

curl 示例

curl -F "file=@photo.heic" \
     -F "target=WebP" -F "quality=85" \
     http://localhost:5080/api/convert \
     -o photo.webp

# 一键预设：HEIC 批量转 JPEG / 扫描件拆页
curl -F "files=@IMG_001.HEIC" -F "files=@IMG_002.HEIC" \
     -F "preset=heic-jpeg" \
     http://localhost:5080/api/batch -o photos.zip

curl -F "files=@scan.tiff" -F "preset=scan-split" \
     http://localhost:5080/api/batch -o pages.zip

# 纯托管处理层 + OCR 裸像素
curl -F "file=@a.png" -F "resizeW=800" \
     -F "brightness=10" -F "watermark=demo" \
     http://localhost:5080/api/process -o a-processed.png

curl -F "file=@a.png" -F "layout=gray8" \
     http://localhost:5080/api/pixels -o a.gray8.raw

# 运维探针与指标（可选鉴权时加 -H "X-Api-Key: $KEY"）
curl http://localhost:5080/api/ready
curl http://localhost:5080/api/metrics
